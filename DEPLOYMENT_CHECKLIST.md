## Render Service Architecture

- **Web Service**: Flask app (Free tier)
- **Worker Service**: Celery worker (Starter tier - needed for CPU-intensive tasks)  
- **Redis**: Message broker (Free tier)

## Post-Deployment Testing

After deployment, test these endpoints:
- `GET /` - Main page
- `GET /health` - Health check
- `POST /process-tiktok` - TikTok processing (requires valid URL)

## Notes

- YOLO model (`yolov8s.pt`) will be downloaded during build
- Temporary files are stored in `/tmp` and cleaned up automatically
- Worker service handles CPU-intensive video processing tasks
- Free tier has limitations on processing time and concurrent requests
